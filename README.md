# Student CRUD Application

A simple Student Management System built with Spring Boot to perform CRUD (Create, Read, Update, Delete) operations on student records.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Maven
- Database: H2

## Features
- Add new students
- View all students
- View student details
- Update student information
- Delete student records

## Getting Started

1. Clone the repository.
2. Configure your database in `application.properties`.
3. Run the application:

   ```bash
   ./mvnw spring-boot:run
   ```

4. Access the application at `http://localhost:8080`.

## Purpose

This project demonstrates basic CRUD operations and database integration using Spring Boot.
